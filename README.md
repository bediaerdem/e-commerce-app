# Flutter Mini Katalog Uygulaması

## Proje Hakkında

Bu proje, Flutter kullanılarak geliştirilen bir mini katalog uygulamasıdır. Uygulama, kullanıcıların ürünleri listeleyebileceği, ürün detaylarını inceleyebileceği ve temel bir sepet simülasyonu deneyimi yaşayabileceği şekilde tasarlanmıştır.

Proje geliştirme sürecinde Flutter’ın temel mimarisi, widget yapısı, sayfa navigasyonu ve veri modelleme mantıkları üzerine odaklanılmıştır.

---

## Özellikler

-  Ürün listeleme ekranı  
-  Ürün detay sayfası  
-  Sayfalar arası navigasyon  
-  GridView ile kart tabanlı tasarım  
-  Sepet sistemi (simülasyon)  
-  Asset ve görsel yönetimi  
-  JSON veri modelleme  

---

##  Kullanılan Teknolojiler

- Flutter  
- Dart  
- Material Design  
- JSON veri modelleme  
- Navigator & Route yapısı

# ⚙️ Kurulum ve Çalıştırma

## Gereksinimler

Projeyi çalıştırmadan önce aşağıdaki araçların yüklü olması gerekir:

- Flutter SDK  
- Dart SDK  
- Visual Studio Code veya Android Studio  
- Android Emulator veya Fiziksel Android cihaz  

---

## Kurulum Adımları

### 1- Repoyu Klonlayın

```bash
git clone REPO_LINK
```

---

### 2- Proje Klasörüne Girin

```bash
cd e-commerce-app/flutter_application_1
```

---

### 3- Gerekli Paketleri Yükleyin

```bash
flutter pub get
```

---

### 4- Bağlı Cihazları Kontrol Edin

```bash
flutter devices
```

---

### 5- Uygulamayı Çalıştırın

```bash
flutter run
```

---

# ▶️ IDE ile Projeyi Açma

## Visual Studio Code ile Açma

```bash
1. Visual Studio Code açılır
2. File → Open Folder seçilir
3. Proje klasörü seçilir
4. Terminal açılır
5. flutter pub get komutu çalıştırılır
6. Run butonu ile proje başlatılır
```

---

## Android Studio ile Açma

```bash
1. Android Studio açılır
2. Open Project seçilir
3. Proje klasörü seçilir
4. Device Manager üzerinden emulator başlatılır
5. Run butonu ile uygulama çalıştırılır
```

---

# Emulator Başlatma

```bash
Android Studio → Device Manager → Emulator → Start
```
